Append-only record of every security-relevant action. No UPDATE/DELETE path
exists anywhere by design; `orgId`/`actorUserId` are plain indexed text (no
FK) so history survives member or org removal. `action` names the verb,
`metadataJson` carries free-form event details as JSON text (upgrade path:
a `jsonb` column — see docs/deployment.md), and the identity `seq` provides
total ordering. A GIN full-text index (see `0000_init.sql`) supports native
Postgres `tsvector` search over `action`/`metadataJson`.
