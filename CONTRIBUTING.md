# Contributing

This is a proprietary starter template. Contributions are not accepted via pull request.

## Reporting Issues

If you find a bug or have a feature request, please [open an issue](https://github.com/verdantstack/sveltekit-postgres-starter/issues) with:

1. **A clear title** describing the problem or request
2. **Steps to reproduce** (for bugs)
3. **Expected vs actual behavior** (for bugs)
4. **Your environment** (Node.js version, OS, npm version, Postgres provider/version)

## Asking Questions

For questions about the starter, please:

1. Check the [documentation](https://verdantstack-site.pages.dev/products/sveltekit-postgres-starter/) first
2. Search [existing issues](https://github.com/verdantstack/sveltekit-postgres-starter/issues) for similar questions
3. Open a new issue with the `question` label if you don't find an answer

## Code of Conduct

- Be respectful and constructive
- Focus on the problem, not the person
- No spam, no self-promotion
